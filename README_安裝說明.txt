GRE 智慧單字本 PWA

部署：
1. 將本 ZIP 解壓縮。
2. 把解壓後的 index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png 全部上傳到 GitHub repository 最外層。
3. GitHub Settings → Pages → Deploy from a branch → main → /(root)。
4. 等待部署完成後，以 Safari 開啟 GitHub Pages 網址。

iPhone / iPad：
Safari → 分享 → 加入主畫面。

Android：
Chrome → 安裝應用程式／加到主畫面。

學習紀錄、錯題、出題次數與星號字會儲存在該網站的瀏覽器本機儲存空間。建議定期使用網站內的匯出功能備份。
新版使用不含品牌名稱的新儲存鍵，並包含舊版學習紀錄的自動遷移相容處理。
